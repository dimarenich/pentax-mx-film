# Курс плёночной фотографии · Pentax MX

Бесплатный курс плёночной фотографии на русском языке: от первой плёнки до зонной системы.
Под камеру Pentax MX и объектив SMC Pentax‑A 50 mm f/1.7.

- 23 модуля и оглавление, 6 ступеней обучения
- живые симуляторы: экспозиция со светодиодами MX, глубина резкости, вспышка, таймер проявки, зонная система
- схемы и исторические фотографии (общественное достояние и свободные лицензии, авторы подписаны на странице)

Тексты — авторский пересказ по мотивам [Lomography School](https://www.lomography.com/school) со ссылками на исходные курсы.
Сайт — один файл `index.html`, публикуется через GitHub Pages.
